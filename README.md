## 이스터에그 기획

이스터에그는 네 동아리의 성격이 서로 다르게 느껴지도록 구성합니다.
이스터에그 발견 여부는 저장하지 않고, 발견 이후에는 다시 발견 이전의 초기 상태로 돌아가도록 합니다.

> 아래 동아리별 구분은 이스터에그 테마 기준입니다. 실제 부스 운영 동아리 표기와 반드시 일치하는 것은 아닙니다.

### NULL — 경계와 페이지 구조 탐색

NULL은 사용자가 평소 지나치는 **페이지의 틈과 끝**을 발견하는 경험으로 구성합니다.

1. **Life is Easter Egg 카드**
   - 별도의 비정상 카드를 추가하지 않고 메인 화면의 기존 `Life is Easter Egg` 부스 카드를 사용합니다.
   - 카드 설명에서 이 카드가 이스터에그임을 알리고 클릭을 유도합니다.
   - 클릭하면 자동 전환을 잠시 멈추고 텍스트 채널 분리·스캔 노이즈 효과와 함께 NULL 이스터에그를 획득합니다.
   - 연출이 끝나면 즉시 다음 카드로 넘어가고, 그 카드에서 자동 전환 타이머를 다시 시작합니다.
   - 실제 부스 수와 필터 결과에는 포함하지 않아 정보 전달을 방해하지 않도록 합니다.
   - '#1 We' 라는 키워드를 얻을 수 있도록 합니다.

2. **페이지의 맨 위와 맨 아래 방문**
   - 45초 안에 최상단과 최하단을 모두 방문하면 발견됩니다.
   - '#2 Code' 라는 키워드를 얻을 수 있도록 합니다.

### s0sCoD3 — 입력과 웹 인터랙션

s0sCoD3는 웹페이지에 직접 명령을 내리거나 텍스트와 상호작용하는 경험으로 구성합니다.

1. **비밀 키워드 입력**
   - Footer에는 기본적으로 `C`, `T`, `D`만 표시되며 입력칸의 테두리와 배경은 완전히 숨깁니다.
   - 각 빈칸에 `ode`, `he`, `ay`를 입력해 `Code The Day`를 완성하면 발견됩니다.
   - 한 입력칸을 완성하면 다음 입력칸으로 자동 이동하며 모바일과 키보드 모두 지원합니다.
   - '#3 The' 라는 키워드를 얻을 수 있도록 합니다.

2. **‘정보과학의 날’ 드래그**
   - 배경색과 동일한 `정보과학의 날` 텍스트를 숨기고, 이를 정확히 드래그해 선택하면 발견됩니다.
   - 모바일에서는 텍스트 길게 누르기 또는 별도의 대체 제스처가 필요합니다.
   - '#4 Day' 라는 키워드를 얻을 수 있도록 합니다.

### 뉴런 — 반응과 게임

뉴런은 마스코트 구름이와 화면이 즉각 반응하는 짧은 게임 경험으로 구성합니다.

1. **구름이 간지럽히기**
   - 메인 화면의 구름이를 여러 번 클릭하면 웃는 전용 이미지와 통통 튀는 동작으로 간지럼에 반응합니다.
   - 과도한 연타를 요구하지 않고 5회 전후로 완료되도록 합니다.
   - 다섯 번 클릭하면 이스터에그를 지급하고, 잠시 웃은 뒤 원래 표정과 위치로 돌아옵니다.
   - '#5 And' 라는 키워드를 얻을 수 있도록 합니다.

2. **마인크래프트 속으로!**
   - 부스 안내 그리드 중 '마인크래프트 속으로'를 누르고 있는 실제 시간을 측정해 약 1.2초 동안 균열이 6단계로 점차 번집니다.
   - `assets/minecraft/image.png`의 2×3 스프라이트를 정확히 잘라 투명 처리한 `crack-01.png`부터 `crack-06.png`까지 사용합니다.
   - 별도의 마이닝 모드 안내는 표시하지 않으며, 이후 다른 셀도 끝까지 누르고 있어야 부서집니다. 전체 셀을 전부 부수면 이스터에그를 지급합니다.
   - 균열이 끝난 카드는 네모난 블록 파티클을 튀긴 뒤 즉시 사라지고, 그리드 공간 뒤에 숨겨진 대형 복셀 구름이 이미지가 조금씩 드러납니다.
   - 진행 중에는 일반 카드의 호버 이동 효과를 끄며, `마인크래프트 속으로` 카드는 처음부터 호버 대신 십자 포인터만 표시합니다.
   - 이 기능은 `전체` 필터에서만 동작합니다. 다른 장소 필터나 8-puzzle로 이동하면 모든 균열·파괴 상태가 초기화됩니다.
   - '#6 Build' 라는 키워드를 얻을 수 있도록 합니다.

### BP — 퍼즐과 이동

BP는 화면 요소를 관찰하고 직접 움직여 해결하는 공간 퍼즐로 구성합니다.

1. **8-puzzle**
   - 부스 안내 셀 분류 중 '8-puzzle'이 존재하도록 합니다.
   - 필터를 선택하면 별도 팝업 없이 기존 부스 그리드가 3×3 퍼즐 보드로 전환됩니다.
   - 그리드에는 부스 설명 셀 여덟 개와 빈칸 하나만 남고, 빈칸을 이용해 순서를 맞춥니다.
   - 번호만 표시하지 않고 실제 부스명과 설명이 담긴 안내 셀 여덟 개를 무작위로 배치합니다.
   - 무작위 배치는 항상 해결 가능한 상태로 생성해야 합니다.
   - '#7 Tomorrow' 라는 키워드를 얻을 수 있도록 합니다.

2. **옮길 수 있는 구름이**
   - 페이지 하단의 별도 구름이를 드래그해 구름이 모양의 흐린 홈에 맞추면 발견됩니다.
   - 화면에는 정답이나 이동 안내 문구를 표시하지 않고 모양만으로 목적지를 추측하도록 합니다.
   - 메인 구름이에는 드래그 기능이 없으며, 두 마스코트의 상호작용은 서로 분리됩니다.
   - 포인터 드래그와 모바일 터치를 지원하며, 키보드 사용자는 구름이에 포커스한 뒤 `Enter`를 누를 수 있습니다.
   - '#8 Together' 이라는 키워드를 얻을 수 있도록 합니다.

## 이스터에그 공통 동작

- 발견 팝업은 획득한 키워드를 가장 크게 강조하고, 아직 찾지 않은 다음 이스터에그의 간접 힌트를 함께 표시합니다.
- 팝업은 자동으로 사라지지 않으며 우측 상단의 `×` 버튼을 눌러야 닫힙니다.
- 팝업이 열린 동안 다른 이스터에그를 실행해도 현재 팝업은 교체되지 않습니다.
- 현재까지 발견한 이스터에그의 현황이나 조각 목록은 화면에 표시하지 않습니다.
- 발견 정보는 `localStorage`, 쿠키뿐 아니라 실행 중인 메모리에도 저장하지 않습니다.
- 각 팝업은 현재 번호 바로 다음 번호의 힌트를 표시하며, `#8` 다음에는 다시 `#1`의 힌트를 표시합니다.
- 사이트는 완성 여부를 자동 판정하지 않습니다. 방문자가 각 키워드를 직접 기록하고 순서대로 조합해야 합니다.
- 각 미니게임과 화면 효과는 발견 직후 초기 모습으로 돌아가 상시 구동 화면에 흔적을 남기지 않습니다.
- 애니메이션은 `prefers-reduced-motion` 설정에서 정적인 효과로 대체합니다.
- 이스터에그 때문에 스크롤, 텍스트 선택, 부스 필터 같은 기본 기능이 오작동하지 않아야 합니다.
- 모바일에서 불가능한 키보드 입력은 별도의 터치 대체 수단을 제공합니다.

## 디자인

- 밝은 화이트·쿨그레이 기반의 라이트 모드
- 청록, 블루, 퍼플, 마젠타 포인트 색상
- 정보과학을 연상시키는 데이터 그리드, 스캔 라인, 시스템 상태 표시
- `Welcome to`와 `Code The Day`의 서체·크기 대비
- 한글은 `Noto Sans KR`과 `맑은 고딕` 폴백을 사용해 굴림체 표시를 방지
- 이스터에그 팝업은 화면 중앙에 표시하고, 8개 안내 문구는 Footer 상단의 독립 영역에 배치
- 행사 정보를 한 화면에서 반복하지 않는 정보 구조
- 메인 구름이의 간지럼 반응과 하단 구름이의 드래그 상호작용

마스코트 파일은 `assets/` 폴더에 있으며, 용도별 표정 에셋을 분리해 사용합니다.

## 프로젝트 구조

```text
.
├─ index.html                  # 페이지 구조와 행사 정보
├─ styles.css                 # 반응형 레이아웃, 디자인, 애니메이션
├─ script.js                  # 부스 데이터, 기본 기능, 이스터에그 8종
└─ assets/
   ├─ sasa-mascot-wave.png     # 메인 화면 기본 상태 구름이
   ├─ sasa-mascot-tickled.png  # 반복 클릭 시 간지럼을 타는 구름이
   ├─ sasa-mascot-worried.png  # 페이지 하단에서 움직일 수 있는 구름이
   └─ minecraft/
      ├─ image.png             # 제공된 마인크래프트 파편 원본
      ├─ crack-01…06.png       # 원본을 분할한 6단계 균열 프레임
      └─ voxel-mascot-reveal.png # 카드 뒤에 숨겨진 대형 복셀 이미지
```

React, Next.js, Vite, Node.js 또는 별도의 패키지 설치가 필요하지 않습니다.

## 실행

`index.html`을 브라우저에서 직접 열 수 있습니다. 로컬 서버가 필요한 경우 원하는 정적 파일 서버를 사용할 수 있습니다.

```bash
python -m http.server 8000
```

이후 `http://localhost:8000`으로 접속합니다.

## 데이터 수정

부스 정보는 [`script.js`](script.js)의 `booths` 배열에서 관리합니다.

