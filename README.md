## 주요 기능

- 전체 화면 환영 화면과 SASA 마스코트
- 5초마다 자동 전환되는 14개 부스 소개 카드
- 이전·다음 카드 수동 조작
- 1층 로비, 2층 로비, S108, S109 장소 필터
- 투명 여백을 정리한 부스 이미지와 설명, 장소, 소요 시간, 수용 인원, 권장 대상을 함께 보여주는 상세 창
- 마인크래프트 이스터에그는 `전체` 필터에서만 활성화되며, 장소 필터에서는 일반 카드와 이미지 상세 창으로 동작
- 장소별 부스 아래의 실시간 부스 현황 링크·QR 삽입 영역
- 부스 상세 창과 동일하게 배경을 흐리게 처리하는 이스터에그 팝업
- PC 중심 반응형 레이아웃
- `prefers-reduced-motion` 접근성 대응
- 별도 빌드 과정이 필요 없는 정적 웹사이트

## 디자인

- 밝은 화이트·쿨그레이 기반의 라이트 모드
- 청록, 블루, 퍼플, 마젠타 포인트 색상
- 정보과학을 연상시키는 데이터 그리드, 스캔 라인, 시스템 상태 표시
- `Welcome to`와 `Code The Day`의 서체·크기 대비
- 한글은 `Noto Sans KR`과 `맑은 고딕` 폴백을 사용해 굴림체 표시를 방지
- 이스터에그 팝업은 화면 중앙에 표시하고, 8개 안내 문구는 페이지 하단 구름이 휴게 공간에 배치
- 행사 정보를 한 화면에서 반복하지 않는 정보 구조
- 메인 구름이의 간지럼 반응과 하단 구름이의 드래그 상호작용

마스코트 파일은 `assets/` 폴더에 있으며, 용도별 표정 에셋을 분리해 사용합니다.

## 실행

`index.html`을 브라우저에서 직접 열 수 있습니다. 로컬 서버가 필요한 경우 원하는 정적 파일 서버를 사용할 수 있습니다.

```bash
python -m http.server 8000
```

이후 `http://localhost:8000`으로 접속합니다.

## 배포

정적 파일만 사용하므로 GitHub Pages, Cloudflare Pages, Netlify 등에서 별도의 빌드 명령 없이 배포할 수 있습니다. 배포 루트는 저장소 최상위 디렉터리로 설정합니다.
